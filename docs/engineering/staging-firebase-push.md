## Sender contract and identity decision

The booking Worker calls the service binding `FCM_SENDER.fetch` at `POST https://fcm-sender.internal/send`. This is not a public endpoint. The new receiver accepts only the existing nine fields, real-package allowlist, staging environment, EN/AR locale, opaque IDs and a bounded token/body. The booking service still authorizes recipients and resolves current destination versions; the sender cannot decide who is a partner or owns a visit. It sends generic text, a replacement tag and the exact Android package restriction. Its reply contains only `accepted`, `invalid_token`, `failed` with a safe code, or `retry` with a safe code and optional bounded delay. Only a typed FCM 404 `UNREGISTERED` retires a token; the booking service fences that retirement by version. No payloads, credentials, destinations or provider bodies are logged.

| Context                  | Credential path                                                                                                                                                                                                              | Status                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Trusted operator machine | Existing Node ADC adapter can refresh an authorized user's short-lived OAuth token.                                                                                                                                          | Operator sign-in required; not used in these tests and not a hosted credential.                          |
| Current booking Worker   | A private service binding carries the job; its existence does not mint a Google token.                                                                                                                                       | No configured runtime issuer, Google-attached account or verified hosted mint.                           |
| Prepared private sender  | Private workload assertion → Google Security Token Service → dedicated service-account access token scoped to `firebase.messaging` (10 minutes). Refresh within the last minute, or once after FCM rejects a token with 401. | Locally tested with fakes. No public route or schedule. Default live switch off; no credential fallback. |
